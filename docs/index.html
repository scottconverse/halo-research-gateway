Windows only / standard MCP / source-backed

One research plane.
Every agent.

Halo Research Gateway is a persistent service on your Windows machine that gives every compatible local AI client the same fourteen tools to find web sources, read pages and documents, and return cited evidence. DSH is the first client, not a dependency. The Gateway does not send email, post to GitHub, buy things or manage accounts.

Status: version 0.3.0. A complete bounded DSH workflow and the installed DSH job lifecycle have passed. Other registered clients share the same MCP contract; their model-selected live calls are tracked separately. See the evidence and what is still open.

Research current browser interception patterns. Prefer official sources, then compare community findings.

Discover

web_search returns candidate sources, with Exa and DDGS fallback.

Read

web_fetch / web_crawl read pages; a signed cursor continues long evidence.

Return

Cited, source-backed packet with warnings for anything missing or partial.

Why it exists

Agent hosts have inconsistent web access.

Some hosts can search but not crawl. Others can fetch a URL but cannot discover it. Separate instances can unknowingly spend the same anonymous search quota or hammer Reddit. Halo centralizes that work in one local process without making DSH dependent on a cloud LLM.

One process owns the cache, rate limits, singleflight coordination, durable jobs and browser concurrency. SQLite holds structured state. The service and its browser descendants run inside a dedicated Windows Job Object, so stopping the Gateway cannot orphan its Chromium tree.

Architecture

The shared layer local agents were missing.

Clients connect over standard Streamable HTTP MCP at one loopback endpoint. The Gateway does not change a client's models, presets, permissions or conversation history.

Tool contract

Fourteen tools. Find, read, cite.

Fetched content is evidence, never instructions. Successful results preserve source URLs, retrieval metadata and warnings, plus a signed cursor when another independently citable page is available.

Public webweb_search · web_fetch · web_crawlDiscover sources, retrieve a known page, or render JavaScript content.
Redditreddit_search · reddit_threadSearch Reddit and read a post plus available RSS comments through one paced queue.
Documentsdocument_extractBounded, citable text from public PDFs and documents, with local English OCR.
Researchdeep_research · github_research · transcript_fetchBuild evidence packets, retrieve read-only GitHub evidence, or public transcript material.
Communitiescommunity_search · community_threadSearch and read technical discussions outside Reddit.
Local targetslocal_fetch · local_crawlRead or render an exact operator-defined private or local target.
Durable workresearch_jobCreate, inspect, pause, resume or cancel a finite research job.

Evidence that survives the turn

Continuation binds immutable evidence and retains collected text across bounded output pages. Cache limits, durable-job checkpoints and restart tests preserve usable evidence; evicted or unavailable results are disclosed.

Fetch and real browser crawl

Read ordinary pages directly, or follow a bounded page and depth frontier with Gateway-owned Chrome. Each source keeps its own citation, and usable pages are retained when another fails.

Operator-owned identity

Encrypted research connections, OAuth Authorization Code with PKCE, a read-only GitHub App, and reviewed cookie-only session import. Models receive opaque connection IDs only.

Network policy in code

Public tools reject loopback, private, link-local and cloud-metadata destinations after DNS resolution, and revalidate redirects. Local access uses separately named exact-target tools.

Bounded, resumable jobs

Research jobs have finite limits and are operator-visible. The installed DSH lifecycle check covered active pause, resume, cancel and restart recovery.

Explicit limits

Recognized challenge pages are not counted as research evidence. Paid CAPTCHA and proxy providers are disabled by default; no real paid call is claimed.

Scope boundary

Research only. By design, not by backlog.

Since 2026-09-02 the governing scope is research-only. The removed features are not a future backlog.

The Gateway does

  • Search, fall back across providers, and read pages, documents, transcripts and discussions.
  • Return citations with warnings for missing or partial results.
  • Run bounded multi-step research and durable jobs.
  • Use research login sessions, copied as cookies only, to read restricted sources.

The Gateway does not

  • Send or draft email, or compose through Gmail.
  • Create or edit GitHub issues or comments.
  • Submit general forms, post, message, buy things or change accounts.
  • Import a whole Chrome profile, saved passwords, autofill, history or bookmarks.

Evidence, not adjectives

What is verified, and what is still open.

The repository keeps dated evidence files for each claim. This page repeats only what those files record.

Verified in the repo

  • A complete model-driven DSH workflow: eight successful Gateway calls, three distinct required sources, continuation, two automatic compactions, and a cited answer within six minutes and 250 words.
  • Installed DSH job lifecycle: active pause with frozen checkpoints, same-job resume, active cancel, Gateway restart recovery, and exact partial-failure reporting.
  • Native Chrome fixtures for cookie-only sessions, exact local paths, WebSockets and cancellation cleanup.
  • Native Exa-to-DDGS quota fallback, and authenticated public GitHub discussion and commit-pinned document pagination in disposable instances.

Still open

  • Real research-login and app-bound cookie acceptance.
  • Broader stress testing and clean-OS and logon acceptance.
  • CapSolver and Bright Data were tested against local fake vendors, not paid APIs.
  • Registered clients other than DSH are not called live-proven until their model selects and completes a Gateway tool.
  • Browser-level DNS pinning inside Chromium is not yet proven.

Quick start

Install the local Gateway, then verify it.

Prerequisites: Windows 11, PowerShell, uv with the locked Python 3.12 environment, Node.js 22 for the install quality gate, Google Chrome for Crawl4AI, and at least one supported MCP host.

  1. Install from the repository root. The installer runs the quality gate, installs the canonical skill, merges supported MCP registrations, optionally registers the at-logon task, and starts the service. It does not rewrite DSH model, context, reasoning, slot or permission settings.

    .\scripts\Install-HaloResearch.ps1 -RegisterTask -RegisterHosts -Start

  2. Verify the installation, including the browser path.

    .\scripts\Test-HaloResearch.ps1 -Browser

  3. Open the operator console at http://127.0.0.1:8765/operator. A healthy installation reports status: ok, result schema 1.5 and database schema 3. Create credentials as connections there, never in TOML, arguments, prompts or Git.

    .\scripts\Start-HaloResearch.ps1   # start
.\scripts\Stop-HaloResearch.ps1    # stop
